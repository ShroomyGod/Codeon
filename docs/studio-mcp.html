Attach Studio as an MCP server

There is no Codeon plugin. Roblox Studio ships its own MCP server — the same one behind Studio's built-in Assistant — and Codeon is simply another client of it. Nothing is installed into Studio and no network socket is opened.

Codeon spawns Roblox's own launcher locally. Your place never leaves the machine.

Steps

  1. In Roblox Studio, open Assistant → MCP (on some versions: Assistant → Manage MCP Servers) and enable the MCP server. This only needs doing once.
  2. Open a place in Studio — Codeon can only see places you have open.
  3. In Codeon, press Connect to Studio (or Reconnect in Settings). Codeon launches Studio's bundled MCP server, handshakes with it, and lists your open Studio windows.
  4. The status chip turns green and shows the place name, plus the number of available tools (around 30).
Ask for a change and you will get a reviewable diff before anything touches your place.

Multiple Studio windows

If more than one place is open, Codeon attaches to one and offers a picker for the rest. Closing the attached window moves Codeon to the first remaining one automatically.

How Codeon finds the server

Codeon resolves Roblox's launcher in order — override, Studio-written launcher, then the newest bundled server:

OrderSourceNotes
1Your overrideFull command line in Settings → Studio attachment
2%LOCALAPPDATA%\Roblox\mcp.batWritten by Studio itself
3Newest Versions\*\StudioMCP.exeFallback when mcp.bat is missing
